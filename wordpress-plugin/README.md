# Matrix WordPress Plugin

A basic WordPress plugin template for the Matrix project.

## Installation

1. Download or clone this plugin into your `wp-content/plugins/` directory
2. Rename the directory to `matrix-plugin`
3. Activate the plugin from the WordPress admin dashboard

## Directory Structure

```
wordpress-plugin/
├── plugin.php              # Main plugin file
├── README.md              # This file
├── includes/
│   └── class-matrix-plugin.php  # Main plugin class
└── admin/
    └── admin-page.php     # Admin interface template
```

## Features

- Object-oriented plugin structure
- Admin menu integration
- Proper WordPress hooks and filters
- Internationalization support (i18n)

## Requirements

- WordPress 5.0 or higher
- PHP 7.2 or higher
